# Invisly Landing Page MVP

## Overview
This document outlines the Minimum Viable Product (MVP) for the Invisly landing page. The landing page is designed as a stealth coding assistant application to help students prepare for technical interviews.

## Page Structure

### 1. Header
- **Logo**: Invisly brand logo
- **Navigation Menu** (Desktop):
  - Features (Anchor link to #features section)
  - Documentation (Link to /documentation page)
  - Pricing (Anchor link to #pricing section)
- **User Authentication**:
  - Sign In button (opens modal)
  - Sign Up button (opens modal)
- **Mobile Menu**:
  - Hamburger menu icon
  - Slide-in menu with same navigation options

### 2. Hero Section
- Main headline and value proposition
- Subheading with brief description
- Call-to-action buttons
- Visual elements/animations

### 3. Brand Logos Slider
- Showcase trusted brands and technologies
- Continuous sliding animation

### 4. Video Demo
- Product demonstration video
- Explanation of core functionality

### 5. Trusted By
- Logos of organizations or institutions that trust the platform

### 6. Glass Effect Demo
- Interactive demo showcasing the glass effect feature
- Visual representation of the product's capabilities

### 7. Bento Grid
- Feature highlights in a grid layout
- Visual and textual explanation of key benefits

### 8. Platform Compatibility
- Display of supported platforms and environments
- Icons representing different operating systems/browsers

### 9. Shortcuts
- Keyboard shortcuts reference
- Quick access to important features

### 10. Pricing
- Subscription plans and pricing tiers
- Feature comparison between plans
- Call-to-action buttons

### 11. Insights Banner
- Statistics and achievements
- User testimonials or metrics

### 12. FAQ
- Frequently asked questions and answers
- Accordion-style expandable sections

### 13. Footer
- **Legal Links**:
  - Privacy Policy (modal dialog)
  - Terms of Service (modal dialog)
  - Disclaimer (direct link to /disclaimer page)
- **Social Media Links**:
  - Email
  - LinkedIn
  - GitHub

  - Twitter/X
- **Copyright Notice**: © 2025 Invisly. All rights reserved.

## Key Features

### Core Functionality
1. **Real-time AI Coding Assistance**
   - Instant help with coding problems
   - Context-aware suggestions

2. **Smart Screenshot Analysis**
   - Upload and analyze coding screenshots
   - Extract and explain code snippets

3. **Complexity Breakdowns**
   - Time and space complexity analysis
   - Step-by-step explanations

### Educational Focus
- Designed exclusively for educational purposes
- Helps students practice and improve coding skills
- Encourages ethical use in learning environments

## User Flow

1. **Visitor Access**
   - View all public content
   - Access documentation
   - Browse features and pricing

2. **Registration**
   - Sign up through modal form
   - Email verification process
   - Account creation

3. **Authenticated User**
   - Full access to platform features
   - Dashboard access
   - Subscription management

## Technical Specifications

### Frontend
- **Framework**: Next.js with React
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **UI Components**: Custom built with shadcn/ui principles

### Backend
- **Authentication**: Clerk
- **Database**: Convex
- **Payments**: Stripe integration

### Deployment
- Hosted on Netlify or similar platform
- Continuous deployment pipeline

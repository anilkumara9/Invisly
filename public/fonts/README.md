# Fonts Directory

To use the Tracing Beam component with the CalSans font, please download the CalSans-SemiBold.woff2 font file and place it in this directory.

## Instructions:

1. Download the CalSans-SemiBold.woff2 font file from a trusted source
2. Place the file in this directory (public/fonts/)
3. The font will be automatically loaded by the application

The component will still work without the specific font, but will fall back to the default sans-serif font.
